**A SIZED BODY, on `feat/sized-body` (2026-10-25),** decision 0033, for Kiyomi-Computation-Systems/chez-http-server#216 (the owner's, for circuit, which streams a file's port and sends it chunked), on the brief of the session that ported the docs site.
- **Measured first.** On this tree a producer's 200 is chunked, and a handler's own `Content-Length: 12` is a 500, logged `invalid-response framing-field`. Node 26.0.0, run here: an over-long write goes whole and the connection is kept, so the client reads the next response as this one's tail; `strictContentLength` throws at `end()` and leaves the response unended. Read from source: Go 1.25 refuses the crossing write whole (`ErrContentLength`) and closes after; Kestrel 9.0 throws on it and turns keep-alive off, and reports "too few bytes written (X of Y)"; hyper 1.7 cuts the frame at the length, keeps the connection and polls the body no more; waitress 3.0.2 cuts and logs, and logs a short body with both counts; gunicorn 23.0.0 cuts silently; PEP 3333 says stop iterating once enough is sent. curl 8.7.1: exactly the length then a close, exit 0; fewer, exit 18. A bare close lost no byte on loopback (4 MiB to a trickling client, 3 of 3).
- **By form, each the recommended option:** a piece past the length is not written, none of it (Go, Kestrel); at the length the producer is asked no more (PEP 3333, hyper); a mismatch closes staged, as after any response; it logs `body-length-mismatch n given`. The name and library as the issue proposes: `(sized-body n producer)` from `(http-server response)`, and the facade.
- **Built.** `(http-server response)`: the `sized-body` record, its length a fixnum, its producer a procedure, each refused otherwise. The serializer: a sized body's head says `Content-Length: n` and writes no body; `serialize-piece` and `serialize-end` take `content-length` mode, the piece unframed, the end nothing; a sized body framed chunked or close-delimited is refused; `response-fault` takes it. The core: `write-action` frames it by its length and keeps its producer, its length and what is left of it (two state fields) where a body of a byte or more is written; `on-body-chunk` counts each piece, lets the producer go at the length, and takes a piece past it as a mismatch; `on-body-end` takes the eof object short of it as one; `mismatch` logs, lets the producer go, sets `body-length-mismatch` unless the connection closes for a reason of its own, and closes staged once the writes complete. `response-framing` already frames any count, so `decisions.sls` changes in its comment alone, and the shells not at all. The facade exports `sized-body`; docs/reference.md has its entry, which `tests/test-reference.sps` (#220) holds.

The move script (script A), for a later base. Run it from the repository's root, on a clean tree:

```sh
#!/bin/sh
# Move the fake shell from tests/ into src/ as (http-server private fake-shell),
# so the Akku package installs it, and leave tests/fake-shell.sls as a shim
# that re-exports it as (fake-shell), with the same exports, so no suite's
# imports change.  Run from the repository's root, on a clean tree.
set -eu

old=tests/fake-shell.sls
new=src/http-server/private/fake-shell.sls
shell=src/http-server/private/shell.sls

[ -f "$old" ] || { echo "move: no $old" >&2; exit 1; }
[ ! -e "$new" ] || { echo "move: $new exists already" >&2; exit 1; }
grep -q '^(library (fake-shell)$' "$old" || { echo "move: $old has no '(library (fake-shell)' line" >&2; exit 1; }
sed -n '2p' "$old" | grep -q '^;;; (fake-shell) ' || { echo "move: $old's second line does not name (fake-shell)" >&2; exit 1; }

# The export form, verbatim: from its "(export" line to the line before the
# first "(import" line.  The form must close on that line: its parentheses
# balance there, and on no line before it.
exports=$(awk '/^[[:space:]]*\(import/ { exit } /^[[:space:]]*\(export/ { p = 1 } p' "$old")
[ -n "$exports" ] || { echo "move: no export form before the import form in $old" >&2; exit 1; }
lines=$(printf '%s\n' "$exports" | wc -l)
printf '%s\n' "$exports" | awk -v lines="$lines" '
  { for (i = 1; i <= length($0); i++) { c = substr($0, i, 1); if (c == "(") d++; else if (c == ")") d-- }
    if (d <= 0 && NR < lines) bad = 1 }
  END { exit (d != 0 || bad) }' ||
  { echo "move: the export form in $old does not end on the line before its import form" >&2; exit 1; }

git mv "$old" "$new"

# The library's name, in its form and in the header's first line.
sed -e 's/^(library (fake-shell)$/(library (http-server private fake-shell)/' \
    -e '2s/^;;; (fake-shell) /;;; (http-server private fake-shell) /' \
    "$new" > "$new.tmp"
mv "$new.tmp" "$new"
grep -q '^(library (http-server private fake-shell)$' "$new" || { echo "move: the library was not renamed" >&2; exit 1; }
sed -n '2p' "$new" | grep -q '^;;; (http-server private fake-shell) ' || { echo "move: the header's first line was not renamed" >&2; exit 1; }

{
  printf '%s\n' \
    '#!r6rs' \
    ';;; (fake-shell) — the fake shell, by the name the suites import it by.' \
    ';;;' \
    ';;; The harness is (http-server private fake-shell), in' \
    ';;; src/http-server/private/fake-shell.sls, where the package installs' \
    ';;; it.  This library re-exports what the suites import, by the name' \
    ';;; they import it by.' \
    '(library (fake-shell)'
  printf '%s\n' "$exports"
  printf '%s\n' '  (import (http-server private fake-shell)))'
} > "$old"

# The libuv shell's header names the fake by its path.
if grep -q "is the fake shell's (tests/fake-shell.sls)\." "$shell"; then
  sed -e "s|is the fake shell's (tests/fake-shell.sls)\.|is (http-server private fake-shell)'s.|" \
      "$shell" > "$shell.tmp"
  mv "$shell.tmp" "$shell"
else
  echo "move: $shell no longer names tests/fake-shell.sls as it did; check its header by hand" >&2
fi
! grep -n 'tests/fake-shell\.sls' "$shell" || { echo "move: $shell still names tests/fake-shell.sls" >&2; exit 1; }

git add "$old" "$new" "$shell"
```
