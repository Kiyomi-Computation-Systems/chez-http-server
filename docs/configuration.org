#+TITLE: Configuration

chez-http-server follows the 12-factor rule for config: every connection limit
has a bounded default and can be overridden from the environment. Timeouts are
given in whole *seconds*; sizes and counts in their own unit. An unset or empty
variable keeps the default; a malformed value (negative or non-numeric) is
refused rather than silently ignored.

| Variable                            | Default   | What it bounds                          |
|-------------------------------------+-----------+-----------------------------------------|
| ~CHEZ_HTTP_READ_HEADER_TIMEOUT~     | 60 s      | time to receive the whole request head  |
| ~CHEZ_HTTP_IDLE_TIMEOUT~            | 75 s      | keep-alive idle time between requests    |
| ~CHEZ_HTTP_BODY_INACTIVITY_TIMEOUT~ | 60 s      | longest gap between body reads           |
| ~CHEZ_HTTP_MAX_HEADER_BYTES~        | 16384     | all header names and values together     |
| ~CHEZ_HTTP_MAX_HEADER_COUNT~        | 100       | number of header fields                  |
| ~CHEZ_HTTP_MAX_HEADER_FIELD_BYTES~  | 8192      | one header name                          |
| ~CHEZ_HTTP_MAX_HEADER_VALUE_BYTES~  | 8192      | one header value                         |
| ~CHEZ_HTTP_MAX_TARGET_BYTES~        | 8192      | size of the request-target               |
| ~CHEZ_HTTP_MAX_BODY_BYTES~          | unbounded | request-body cap (~unbounded~ disables)  |
| ~CHEZ_HTTP_PIPELINE_CAP~            | 1         | in-flight pipelined requests             |
| ~CHEZ_HTTP_READ_BUFFER_SIZE~        | 16384     | per-connection read buffer               |
| ~CHEZ_HTTP_REQUIRE_HOST~            | true      | HTTP/1.1 requests must send ~Host~       |

A request over any of the four header limits gets ~431~, and one whose target
is over its limit gets ~414~. Either way the connection closes. What else a
target must be is in [[file:request-targets.org][request-targets.org]].

~CHEZ_HTTP_REQUIRE_HOST~ is ~true~ or ~false~, nothing else. With ~false~, an
HTTP/1.1 request with no ~Host~ is served instead of getting ~400~. The other
~Host~ rules always apply: see [[file:host-header.org][host-header.org]].

These are nginx-style bounded defaults (decision 0005). They live in the pure
library ~(http-server limits)~: the shell reads the environment and hands the
values to the core, so the limits are exercised in tests with no environment at
all.
